## 🧠 Overview
The **Blinkit Dashboard** is an interactive and analytical visualization project built using **Power BI**.  
It highlights **sales performance**, **customer preferences**, and **outlet-level profitability** to drive business insights and data-backed decision-making.  

Designed with clean visuals and intuitive filters, this dashboard provides a seamless analytical experience.

---

## 🎯 Key Objectives
- 📊 Analyze **sales trends** across item categories and outlet types.  
- 🎯 Track **KPIs** including total sales, average rating, and outlet count.  
- 📈 Identify **top-performing** and **underperforming outlets**.  
- 🔍 Enable **dynamic filtering** for deep-dive insights.  

---

| Purpose | Tools / Technologies Used |
|----------|----------------------------|
| **Data Visualization** | Power BI |
| **Data Transformation** | Power Query |
| **Data Modeling** | Star Schema with Relationships |
| **Data Source** | Excel / CSV Dataset |
| **Visuals Used** | KPI Cards, Bar Charts, Donut Charts, Line Charts, Slicers |

---

## 📈 Insights Derived
- 🔹 Highest sales generated by **Supermarket outlets**.  
- 🔹 **Low-fat items** contribute significantly to overall revenue.  
- 🔹 **Tier 3 outlets** show strong customer ratings with moderate sales.  
- 🔹 Clear visualization of **sales vs rating correlation** across outlets.  

---

## 🧩 Dashboard Features
✨ **Interactive Filters:** Outlet Type, Item Type, and Region  
📊 **Dynamic KPIs:** Real-time display of total sales and outlet metrics  
🎨 **Modern Design:** Color-coded themes and consistent layout  
🔄 **Data Refresh Support:** Easy data update with Power Query integration
